Small ChallengeIAM security maintenance system

Bastion EC2와 IAM 사용자·그룹을 구성하고, MFA 없이는 S3 버킷 삭제를 막는 정책과 ap-northeast-2 리전 리소스만 접근하도록 제한하는 정책을 적용하는 IAM 보안 과제입니다.

VPCEC2IAM
📝 채점기준 보기

개요

IAM security maintenance system

Module: IAM security

  • 원격 접속 가능한 EC2 Instance를 생성하십시오. Bastion 인스턴스는 admin 권한을 가지며 curl, jq, awscli v2를 사용할 수 있어야 합니다.
  • 정책을 실험할 사용자로 IAM user “tester”를 생성합니다. 해당 유저에게는 AdministratorAccess 관리형 정책과 MFA를 활성화하지 않으면 S3 버킷을 삭제할 수 없는 mfaBucketDeleteControl 정책을 만들어서 적용합니다.
  • 또한, 사용자 그룹 “user_group_kr”을 만들어서 “tester”를 그룹에 포함 시킵니다. 한국에서 사용되는 모든 user는 “user_group_kr”에 속한다고 가정할 때, 사용자가 ap-northeast-2 리전의 리소스에만 접근할 수 있는 정책인 regionAccessControl을 만들어서 한국의 모든 사용자에게 적용되도록 합니다.
  • 글로벌 서비스 등의 외부 리전의 리소스에 대한 모든 접근을 차단해야 합니다.

사용 기술

분류 항목
AWS services VPC, EC2, IAM
Other S/W -

선수 유의사항

  1. 선수의 계정에는 비용의 제한이 존재하며, 이보다 더 높게 요금이 부과될 시 계정 사용이 불가능할 수 있습니다.
  2. 문제에 제시된 괄호 박스 <>는 변수를 뜻함으로 선수가 적절히 변경하여 사용해야 합니다.
  3. EC2 인스턴스의 TCP 80/443 outbound는 anyopen하여 사용할 수 있도록 합니다.
  4. 과제의 Bastion 서버에서 대부분의 채점이 이루어짐으로 인스턴스를 생성하지 않았거나 종료된 상태면 채점이 불가능하니 각별히 주의하도록 합니다.
  5. 과제 종료 시 진행 중인 테스트를 모두 종료하여 서버에 부하가 발생하지 않도록 합니다.
  6. 별도 언급이 없는 경우, ap-northeast-2 리전에 리소스를 생성하도록 합니다.
  7. 모든 리소스의 이름, 태그, 변수와 값은 대소문자를 구분합니다.
  8. 과제 종료 시 불필요한 리소스는 전부 삭제하시길 바랍니다.
