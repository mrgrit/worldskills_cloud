1. 아래 명령어를 입력합니다. 

CT=$(date +%H%M%S) 

RES=$(curl -s -w '\n%{time_total}' -X POST -H 'Content-Type: application/json' \ 

      -d '{"device_id":"line-01-equip-'$CT'","metric":"temperature_c","value":82.4}' \ 

      http://$ALB/ingest) 

BODY=$(echo "$RES" | head -1) 

TIME=$(echo "$RES" | tail -1) 

ID=$(echo "$BODY" | jq -r .id) 

 

echo "POST ${TIME}s  $(awk -v t=$TIME 'BEGIN{print (t<=2)?"OK (2초 이내)":"FAIL (2초 초과)"}')" 

echo "ID = $ID" 

 

RES=$(curl -s -m 5 -w '\n%{http_code} %{time_total}' -X GET http://$ALB/v1/readings/$ID) 

BODY=$(echo "$RES" | head -1) 

CODE=$(echo "$RES" | tail -1 | cut -d' ' -f1) 

TIME=$(echo "$RES" | tail -1 | cut -d' ' -f2) 

 

if [ "$CODE" = "200" ]; then 

    echo "GET ${TIME}s  OK (5초 이내)" 

    echo "$BODY" 

else 

    echo "GET  FAIL (HTTP $CODE)" 

fi 

 

2. 출력에 아래 POST와 GET이 모두 OK로 성공한 이력이 포함되어 있는지 확인합니다.

1. 아래 명령어를 실행합니다.

BODY=$(curl -s -X POST -H 'Content-Type: application/json' \

echo "ID = $ID" 

 

for i in 1 2 3; do 

    RES=$(curl -s -m 5 -w '\n%{http_code}' -X GET http://$ALB/v1/readings/$ID) 

    BODY=$(echo "$RES" | head -1) 

    CODE=$(echo "$RES" | tail -1) 

    if [ "$CODE" = "200" ]; then 

        echo "#$i  $BODY" 

    else 

        echo "#$i  FAIL" 

    fi 

done

* 5-3이 성공한 경우만 득점이 인정됩니다. 

1.아래 명령어를 입력하여 EC2와 ECS Fargate 개수를 확인합니다. 

EC2=$(aws ec2 describe-instances --region $REGION \ 

      --filters Name=instance-state-name,Values=running \ 

      --query 'length(Reservations[].Instances[])' --output text) 

 

# shgold-cluster 의 Running 중인 Fargate 컨테이너 갯수 

TASKS=$(aws ecs list-tasks --cluster shgold-cluster --desired-status RUNNING --region $REGION \ 

        --query 'taskArns[]' --output text) 

 

if [ -z "$TASKS" ]; then 

    FARGATE=0 

else 

    FARGATE=$(aws ecs describe-tasks --cluster shgold-cluster --tasks $TASKS --region $REGION | \ 

              jq '[.tasks[].containers[] | select(.lastStatus=="RUNNING")] | length') 

fi 

 

echo "Running EC2 인스턴스     : $EC2" 

echo "Running Fargate 컨테이너 : $FARGATE" 

 

2. EC2 개수가 0이고, Running 상태인 Fargate 개수가 1개 이상이면 득점으로 인정합니다. 

Running EC2 인스턴스     : 0 

Running Fargate 컨테이너 : 2
