Small ChallengeDynamic IAM Role Authorization Enforcement

직원 사용자가 EC2 역할에 권한을 추가하면 CloudTrail·CloudWatch로 감지하고 Lambda 함수가 3분 이내에 자동으로 삭제하도록 하여, 관리자만 EC2 역할에 권한을 추가할 수 있게 하는 클라우드 거버넌스 과제입니다.

IAMCloudTrailCloudWatchLambdaEC2
📝 채점기준 보기

개요

Dynamic IAM Role Authorization Enforcement — Module: 8) Cloud governance

EC2 보안을 위해 관리자만 EC2 역할에 권한을 추가할 수 있어야 합니다.

사용 기술

분류 항목
AWS VPC, EC2, CloudWatch, Lambda, IAM
Other S/W -

선수 유의사항

  1. 선수의 계정에는 비용제한이 존재하며, 이보다 더 높게 과금될 시 계정사용이 불가능할 수 있습니다.
  2. 문제에 제시된 괄호박스 <> 는 변수를 뜻함으로 선수가 적절히 변경하여 사용해야 합니다.
  3. EC2 인스턴스의 TCP 80/443 outbound 는 anyopen 하여 사용할 수 있도록 합니다.
  4. 과제 종료 시 진행 중인 테스트를 모두 종료하여 서버에 부하가 발생 하지 않도록 합니다.
  5. 별도 언급이 없는 경우, ap-southeast-1 리전에 리소스를 생성하도록 합니다.

요구사항

  • 두 개의 IAM 사용자를 생성합니다. AdministratorAccess 권한을 가진 관리자 사용자와 IAMFullAccess 권한을 가진 직원 사용자입니다.
  • 모든 IAM 활동은 CloudTrail을 통해 관찰되며 로그는 모두 CloudWatch로 전송되어야 합니다.
  • 기본적으로 EC2가 가지고 있는 역할의 권한은 AmazonSSMManagedInstanceCore 권한입니다.
  • 직원 사용자가 EC2 역할에 권한을 추가하면 Lambda 함수가 해당 권한을 3분 이내에 자동으로 삭제하고, CloudWatch에서 경고 알림이 발생해야 합니다.
  • 채점을 위해 기본 VPC를 이용하여 AdministratorAccess 권한을 가진 Bastion을 생성합니다.
