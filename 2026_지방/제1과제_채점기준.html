1. 채점 시 유의사항 

직 종 명 

클라우드컴퓨팅 

※ 다음 사항을 유의하여 채점하시오. 

 

1) AWS의 지역은 ap-northeast-2을 사용합니다. 

2) 웹페이지 접근은 크롬이나 파이어폭스를 이용합니다. 

3) 웹페이지에서 언어에 따라 문구가 다르게 보일 수 있습니다. 

4) shell에서의 명령어의 출력은 버전에 따라 조금 다를 수 있습니다. 

5) 채점 진행 전 환경 셋업을 위해 다음 사항을 확인해야 합니다. 

  - Bastion에 SSH로 접근 가능한지 확인합니다. 

  - Bastion에서 awscli, curl이 설치되었는지 확인합니다. 

  - Bastion에서 IAM Role이 맵핑되어 awscli로 AWS 모든 리소스에 접근 가능한지 확인합니다. 

0 - aws sts get-caller-identity 명령을 통해 선수의 계정이 아닌 다른 계정에 접근하고 있는지 확인합니다. 만약, 다른 계정이라면 부정행위를 의심할 수 있습니다. 

6) 문제지와 채점지에 있는 <> 는 변수입니다. 해당 부분을 변경해 입력합니다. 

7) 채점은 문항 순서대로 진행해야 합니다. 

8) 삭제된 내용은 되돌릴 수 없으므로 유의하여 채점을 진행합니다. 

9) 이의신청까지 종료된 이후 선수가 생성한 클라우드 리소스를 삭제합니다. 

10) 부분 점수가 있는 문항은 채점 항목에 부분 점수가 적혀져 있습니다. 

11) 부분 점수가 따로 없는 문항은 전체 다 맞아야 점수로 인정됩니다. 

12) 채점 전 채점환경 구성을 위해 ~/.aws/config에 아래 내용이 추가되도록 합니다. 

        ///// 

        [default] 

        region = ap-northeast-2 

        output = json 

        /////

순번 

채점 항목 

0 

1) 웹 브라우저로 EC2 콘솔에 접속합니다. 

2) 선수가 생성한 Bastion(worldpay-bastion)에 SSH나 SSM(Sessions Manager)를 사용하여 접속합니다. 

3) 채점 시 ap-northeast-2 리전을 사용합니다. 다음과 같이 실행합니다. 

$ aws configure set region ap-northeast-2 

4) 제공된 채점 스크립트 파일을 업로드 하여 사용할 수 있습니다. 다음과 같이 실행합니다. 

$ bash mark.sh 

1-1 

1) 아래 명령어를 실행합니다. 

$ aws ec2 describe-vpcs --filter Name=tag:Name,Values=worldpay-app-vpc --query Vpcs[].VpcId --output text 

2) vpc id가 출력되는지 확인합니다. 

1-2 

1) 아래 명령어를 실행합니다. 

$ aws ec2 describe-vpcs --filter Name=tag:Name,Values=worldpay-db-vpc --query Vpcs[].VpcId --output text 

2) vpc id가 출력되는지 확인합니다. 

1-3 

1) 아래 명령어를 실행합니다. 

$ aws ec2 describe-vpcs --filter Name=tag:Name,Values=worldpay-app-vpc --query "Vpcs[].CidrBlock" --output text 

$ aws ec2 describe-vpcs --filter Name=tag:Name,Values=worldpay-db-vpc --query "Vpcs[].CidrBlock" --output text 

2) 출력되는 결과가 "10.0.0.0/16", "10.100.0.0/16"인지 확인합니다. 

1-4 

1) 아래 명령어를 실행합니다. 

$ aws ec2 describe-subnets --filter Name=tag:Name,Values=worldpay-app-subnet-a --query "Subnets[0].CidrBlock" --output text 

$ aws ec2 describe-subnets --filter Name=tag:Name,Values=worldpay-db-subnet-c --query "Subnets[0].CidrBlock" --output text 

2) 출력되는 결과가 "10.0.10.0/24", "10.100.1.0/24"인지 확인합니다. 

1-5 

1) 아래 명령어를 실행합니다. 

$ aws ec2 describe-route-tables --filter Name=tag:Name,Values=worldpay-pub-rt --query "RouteTables[].Tags[?Key=='Name'].Value" --output text  

$ aws ec2 describe-route-tables --filter Name=tag:Name,Values=worldpay-app-rt-a --query "RouteTables[].Tags[?Key=='Name'].Value" --output text  

$ aws ec2 describe-route-tables --filter Name=tag:Name,Values=worldpay-app-rt-c --query "RouteTables[].Tags[?Key=='Name'].Value" --output text  

$ aws ec2 describe-route-tables --filter Name=tag:Name,Values=worldpay-db-rt --query "RouteTables[].Tags[?Key=='Name'].Value" --output text  

2) 출력되는 결과가 "worldpay-pub-rt", "worldpay-app-rt-a", "worldpay-app-rt-c", "worldpay-db-rt"인지 확인합니다. 

1-6 

1) 아래 명령어를 실행합니다. 

$ aws ec2 describe-vpc-peering-connections --filter Name=tag:Name,Values=worldpay-vpc-peering --query VpcPeeringConnections[].[AccepterVpcInfo.CidrBlock,RequesterVpcInfo.CidrBlock] --output text 

2) 출력되는 결과가 "10.0.0.0/16", "10.100.0.0/16"인지 확인합니다. 순서는 다를 수 있습니다. 

1-7 

1) 아래 명령어를 실행합니다. 

$ aws ec2 describe-vpc-peering-connections --filter Name=tag:Name,Values=worldpay-vpc-peering --query VpcPeeringConnections[].[AccepterVpcInfo.PeeringOptions.AllowDnsResolutionFromRemoteVpc,RequesterVpcInfo.PeeringOptions.AllowDnsResolutionFromRemoteVpc] --output text 

2) 출력되는 결과가 모두 "True"인지 확인합니다. 

1-8 

1) 아래 명령어를 실행합니다. 

$ aws ec2 describe-network-acls --filter Name=tag:Name,Values=worldpay-db-nacl --query "NetworkAcls[].Associations[].SubnetId" --output text 

2) 2개의 subnet id가 출력되는지 확인합니다. 

1-9 

1) 아래 명령어를 실행합니다. 

$ aws ec2 describe-network-acls --filter Name=tag:Name,Values=worldpay-db-nacl --query "NetworkAcls[].Entries[?(!(Egress) && RuleAction=='allow')].CidrBlock" --output text 

2) 출력되는 결과가 "0.0.0.0/0"을 포함하지 않는지 확인합니다. 

1-10 

1) 아래 명령어를 실행합니다. 

$ aws ec2 describe-network-acls --filter Name=tag:Name,Values=worldpay-db-nacl --query "NetworkAcls[].Entries[?(@.Egress && RuleAction=='allow')].CidrBlock" --output text 

2) 출력되는 결과가 "0.0.0.0/0"을 포함하지 않는지 확인합니다. 

1-11 

1) 아래 명령어를 실행합니다. 

$ aws ec2 describe-flow-logs --query FlowLogs[].ResourceId --output text 

2) 2개의 vpc id가 출력되는지 확인합니다. 

1-12 

1) 아래 명령어를 실행합니다. 

$ aws ec2 describe-vpc-endpoints --query VpcEndpoints[].ServiceName | grep secretsmanager 

2) 출력되는 결과가 "?"인지 확인합니다. 

2-1 

1) 아래 명령어를 실행합니다. 

$ aws autoscaling describe-auto-scaling-groups --query AutoScalingGroups[].AutoScalingGroupName --output text 

2) 출력되는 결과가 "worldpay-asg"인지 확인합니다. 

2-2 

1) 아래 명령어를 실행합니다. 

$ aws autoscaling describe-auto-scaling-groups --auto-scaling-group-names worldpay-asg --query AutoScalingGroups[].MinSize  --output text  

2) 출력되는 결과가 "2"인지 확인합니다. 

2-3 

1) 아래 명령어를 실행합니다. 

$ aws ec2 describe-instances --query "Reservations[].Instances[].Tags[?Key=='Name'].Value" --output text 

2) 출력되는 결과가 "worldpay-app"을 포함하는지 확인합니다. 

2-4 

1) 아래 명령어를 실행합니다. 

$ aws autoscaling describe-auto-scaling-groups --auto-scaling-group-names worldpay-asg --query AutoScalingGroups[].Instances[].InstanceType --output text 

2) 출력되는 결과가 모두 "t3.micro"인지 확인합니다. 

2-5 

1) 아래 명령어를 실행합니다. 

$ aws autoscaling describe-policies --auto-scaling-group-name worldpay-asg --query ScalingPolicies[].AutoScalingGroupName --output text 

2) 출력되는 결과가 "worldpay-asg"인지 확인합니다. 

3-1 

1) 아래 명령어를 실행합니다. 

$ aws rds describe-db-clusters --db-cluster-identifier worldpay-rds --query DBClusters[].DBClusterIdentifier --output text 

2) 출력되는 결과가 "worldpay-rds"인지 확인합니다. 

3-2 

1) 아래 명령어를 실행합니다. 

$ aws rds describe-db-instances --query DBInstances[].DBInstanceClass --output text 

2) 출력되는 결과가 모두 "db.t3.medium"인지 확인합니다. 

3-3 

1) 아래 명령어를 실행합니다. 

$ aws rds describe-db-clusters --db-cluster-identifier worldpay-rds --query DBClusters[].StorageEncrypted --output text 

2) 출력되는 결과가 "True"인지 확인합니다. 

3-4 

1) 아래 명령어를 실행합니다. 

$ aws rds describe-db-clusters --db-cluster-identifier worldpay-rds --query DBClusters[].Port --output text 

2) 출력되는 결과가 "3307"인지 확인합니다. 

3-5 

1) 아래 명령어를 실행합니다. 

$ aws rds describe-db-instances --query DBInstances[].PubliclyAccessible --output text 

2) 출력되는 결과가 모두 "False"인지 확인합니다. 

4-1 

1) 아래 명령어를 실행합니다. 

$ aws secretsmanager list-secrets --filters Key=name,Values=[worldpay-secret] --query SecretList[].Name --output text 

2) 출력되는 결과가 "worldpay-secret"인지 확인합니다. 

4-2 

1) 아래 명령어를 실행합니다. 

$ aws secretsmanager list-secrets --filters Key=name,Values=[worldpay-secret] --query SecretList[].KmsKeyId --output text 

2) KMS key ARN이 출력되는지 확인합니다. 

4-3 

1) 아래 명령어를 실행합니다. 

$ aws secretsmanager get-secret-value --secret-id worldpay-secret --query SecretString --output text 

2) username이 admin이 아닌지 확인합니다. 

5-1 

1) 아래 명령어를 실행합니다. 

$ aws elbv2 describe-load-balancers --names worldpay-alb --query LoadBalancers[].LoadBalancerName --output text  

2) 출력되는 결과가 "worldpay-alb"인지 확인합니다. 

5-2 

1) 아래 명령어를 실행합니다. 

$ aws elbv2 describe-load-balancers --names worldpay-alb --query LoadBalancers[].AvailabilityZones[].ZoneName --output text 

2) 출력되는 결과가 "ap-northeast-2a", "ap-northeast-2c"인지 확인합니다. 순서는 다를 수 있습니다. 

5-3 

1) 아래 명령어를 실행합니다. 

$ ALB_ARN=$(aws elbv2 describe-load-balancers --names worldpay-alb --query LoadBalancers[].LoadBalancerArn --output text) 

$ aws elbv2 describe-listeners --load-balancer-arn $ALB_ARN --query Listeners[].DefaultActions[].FixedResponseConfig.StatusCode --output text 

2) 출력되는 결과가 "403"인지 확인합니다. 

6-1 

1) 아래 명령어를 실행합니다. 

$ ALB_ENDPOINT=$(aws elbv2 describe-load-balancers --names worldpay-alb --query LoadBalancers[].DNSName --output text) 

$ output=$(curl -s http://$ALB_ENDPOINT/v1/users -H "Content-type: application/json" -d '{"name": "marking-user", "age": 999}') 

$ uid=$(echo $output | grep -o '"uid":[0-9]*' | grep -o '[0-9]*') 

$ echo $output 

2) 출력되는 결과가 {"uid":<숫자>} 형태인지 확인합니다.  

6-2 

1) 아래 명령어를 실행합니다. 

$ curl -s http://$ALB_ENDPOINT/v1/users?uid=$uid 

2) 출력되는 결과가 {"name":"marking-user","age":999}인지 확인합니다. 

6-3 

1) 아래 명령어를 실행합니다. 

$ curl -sI http://$ALB_ENDPOINT/v1/users123 | head -n1 

2) 출력되는 결과가 "403"을 포함하는지 확인합니다. 

7-1 

1) 아래 명령어를 실행합니다. 

$ aws logs describe-log-groups --query "logGroups[?logGroupName=='worldpay-log-group'].logGroupName" --output text 

2) 출력되는 결과가 "worldpay-log-group"인지 확인합니다.

2) 출력되는 결과가 "30"인지 확인합니다.

$ aws logs tail worldpay-log-group --since 0 | grep marking-user
