채점 방법

  1. 웹브라우저로 선수의 AWS 계정에 로그인 후 각 문제에서 지시하는 AWS region으로 이동합니다.
  2. CloudShell을 실행합니다.
  3. 제공된 채점 스크립트 파일을 업로드 하여 사용할 수 있습니다. 다음과 같이 실행합니다.
$ bash mark.sh

1-1. VPC 생성 · 1점

채점 방법

  1. ap-northeast-1 리전으로 이동합니다.
  2. 새로운 cloud shell을 실행합니다.
  3. 아래 명령어를 실행합니다.
$ aws ec2 describe-vpcs --filter Name=tag:Name,Values=sharing-vpc --query Vpcs[].VpcId --output text

기대 결과

  • vpc id가 출력되는지 확인합니다.

1-2. Subnet 생성 · 1점

채점 방법

  • 아래 명령어를 실행합니다.
$ aws ec2 describe-subnets --filter Name=tag:Name,Values=sharing-subnet-a --query "Subnets[0].CidrBlock" --output text
$ aws ec2 describe-subnets --filter Name=tag:Name,Values=sharing-subnet-b --query "Subnets[0].CidrBlock" --output text

기대 결과

  • 출력되는 결과가 "10.100.0.0/24", "10.100.1.0/24"인지 확인합니다.

기대 결과

  • 출력되는 결과가 "sharing-asg"인지 확인합니다.

1-8. Instance 재부팅 후 접속 · 1.5점

참고

항목 이름은 "재부팅"이지만, 실제 채점 절차는 인스턴스를 재부팅하는 것이 아니라 모두 삭제(terminate)한 뒤 ASG가 새로 띄운 인스턴스에서 EFS 자동 마운트를 확인하는 것입니다.

채점 방법

  1. EC2 콘솔로 이동합니다.
  2. 생성되어 있는 모든 EC2 인스턴스를 삭제(terminate)합니다.
  3. 인스턴스가 새로 실행되면 SSM으로 연결합니다.
  4. 아래 명령어를 실행합니다.
$ sudo su -
$ df | grep /mnt/efs

기대 결과

  • 출력되는 결과가 "10.100.x.x"와 "/mnt/efs"를 포함하는지 확인합니다.

1-9. 파일 업로드 · 1.5점

채점 방법

  • SSM에 연결된 상태에서 아래 명령어를 실행합니다.
$ echo "marking9999" > /mnt/efs/mark9999.txt
$ ls /mnt/efs

기대 결과

  • 출력되는 결과가 "mark9999.txt"를 포함하는지 확인합니다.

채점 방법

  2. 아래 명령어를 실행합니다.

기대 결과

  • 출력되는 결과가 "mark9999.txt"를 포함하는지 확인합니다.
