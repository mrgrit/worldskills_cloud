참고

모든 Aspect의 Type은 M (Measurement)이며, Judg Score 칸은 원문에서 모두 비어 있어 생략함. 표의 열: Type = Aspect Type (M = Meas, J = Judg), Extra Aspect Description = Extra Aspect Description (Meas or Judg) OR Judgement Score Description (Judg only), Requirement = Requirement (Measurement Only), Calc Row = Calculation Row (Export only). Calc Row 번호는 아래 Calculations 시트의 행 순서(1 = Pass/Fail, 2 = Full/Half/Quarter 2 Marks, 3 = Clues Used, 4~7 = SRR, 8 = Player Ranking)에 해당함.

참고

Day 3의 Challenge1~Challenge12는 Day 3 문서 Module 1의 트러블슈팅 챌린지 12개에, "Cloud Questing challenge" task1~task3는 Module 2 Quest(Security Chaos)에 해당하지만, 챌린지 이름과 번호의 대응은 원문(채점표·문제지 모두)에 없음.
